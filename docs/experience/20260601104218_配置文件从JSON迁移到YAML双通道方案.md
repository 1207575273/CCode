# 配置文件从 JSON 迁移到 YAML（双通道 + 校验闸）

> 时间: 2026-06-01
> 状态: 已实现并在真实配置上验证通过
> 动机: JSON 不支持注释，配置项含义只能靠外部文档；改为 YAML 后可在文件内自解释。

---

## 1. 完整性调查结论（动手前必读）

配置存在**两条** IO 通道，改造前两条都直接读写 `config.json`：

1. `src/config/config-manager.ts` 的 `ConfigManager` —— 运行时 load/save，全项目 **22 个消费点全部收口于此**（`configManager.load()/save()`），无一处绕过。
2. `src/core/initializer.ts` —— 启动期创建默认 / 补全字段 / 损坏备份 / apiKey 诊断，**还内嵌一份重复的 DEFAULT_CONFIG**。

只改 (1) 会与 (2) 双写打架（启动时 initializer 先写 json，再被迁成 yml）。
解决：让 `ConfigManager` 成为**唯一配置权威**，新增 `ensureInitialized()`，initializer 委托给它，消除第二条 IO 通道和重复默认值。

全字段清单：`defaultProvider` / `defaultModel` / `subAgentModel?` / `providers.<name>{apiKey,baseURL?,protocol?,models[],visionModels?}` / `statusBar?` / `memory{enabled?,embedding{apiKey?,baseURL?,model?,dimension?,provider?}}`。
注意 `memory.embedding.provider` interface 原先未声明但实际存在 —— 迁移必须保留未知嵌套字段（已补进 `EmbeddingConfig`）。

## 2. 双通道读取优先级

```
config.yml / config.yaml 存在 → 解析 YAML（真源）
否则 config.json 存在        → 解析 JSON（legacy）→ 触发迁移
都不存在                     → 写默认 config.yml
```

## 3. 迁移安全闸（“切换成功才变革”的落点）

```
1. 解析 config.json
2. 生成 config.yml（带中文头注释）
3. 回读 config.yml，与原 JSON 深度相等比较（canonicalize 后忽略 key 顺序）  ← 闸门
4. 通过 → renameSync 备份 config.json -> config.json.bak，此后 yml 为真源、写也写 yml
5. 失败 → 删除半成品 yml，#migrationFailed 置位，降级继续用 json，绝不删 json
```

回读校验闸保证：只有 YAML 能无损表达原数据时才切换，否则零数据风险地退回 JSON。

## 4. homedir 防御式解析（path-utils.ts）

`os.homedir()` 在沙箱/容器/受限 shell 下可能返回 `/`、空串或不存在路径。
新增 `resolveHomeDir()`：多来源回退（os.homedir → win 的 USERPROFILE / HOMEDRIVE+HOMEPATH，类 Unix 的 HOME）并用 `existsSync` 校验，保证返回真实存在的目录。
新增 `ccodeHome()`：默认 `<home>/.ccode`，支持 `CCODE_HOME` 环境变量覆盖。

## 5. 测试隔离修复（顺带发现的真实 bug）

改造期间发现：全量单测会经由某被测模块触发**绑定真实 `~/.ccode` 的 configManager 单例**，把开发者真实配置迁掉。
根治：`tests/setup/ccode-home.ts`（vitest setupFiles）在测试启动时把 `CCODE_HOME` 重定向到临时目录。验证：全量单测后真实 `~/.ccode` mtime 不变。

## 6. 验证证据

- 9 条 config-manager 单测 + 5 条迁移/初始化用例全绿；tsc 0 错误。
- 真实配置迁移：`yml == 原 json` 深度一致 [PASS]，4 个 provider 全保留，`memory.embedding.provider=glm`、`dimension=2048` 保留，头注释正常。
- 原 config.json 三重备份：`config.json.bak`（自动）+ `config.json.manual-bak-20260601`（手动）。
